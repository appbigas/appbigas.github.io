# ReactorAI

ReactorAI is a free AI chat client for macOS, iOS, and Windows that lets you switch between local Ollama models and cloud Gemini with one app. Core features are always free.

## Download
- macOS & iOS: https://apps.apple.com/eg/app/reactorai/id6739567267
- Windows: https://apps.microsoft.com/store/detail/9NLWPTD23PG0?cid=DevShareMCLPCB
- Website: https://appbigas.com

## What you get
- Connect to Ollama locally or remotely and use Google Gemini side by side.
- Model switching, session management, and chat history out of the box.
- Vision support (send images), code-friendly responses, and multilingual chats.
- Privacy-first: local models stay local unless you choose cloud.
- Light/dark themes with a simple toggle.
- MCP servers (early support) so models can interact with external tools and data.
